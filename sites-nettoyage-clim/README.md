# Sites d'exemple — nettoyage de climatiseurs muraux

Trois directions de design différentes pour « Thermo-Propre » (nom de travail du plan d'affaires).
Construites en suivant le skill `frontend-design` : plan de design propre au sujet, revue contre
les looks génériques, build, puis autocritique sur capture d'écran.

Prix repris tels quels de `devis-clim/references/tarifs.md` (139 / 129 / 119 / 109 $ par unité,
options, zones A/B, TPS 5 % + TVQ 9,975 %, minimum 120 $). Ces montants sont encore marqués
« EXEMPLE » dans le skill : à confirmer avant mise en ligne. Téléphone 514 555-0142 = fictif.

| Fichier | Idée centrale |
|---|---|
| `a-fiche-de-service.html` | Le calculateur de soumission est le hero, présenté comme une fiche de service. Coupe annotée de la tête murale. |
| `b-la-turbine.html` | Curseur avant/après sur une turbine encrassée (canvas). Signes d'encrassement, 3 niveaux de nettoyage. |
| `c-deux-saisons.html` | Année de la thermopompe au Québec mois par mois ; fenêtres printemps/automne, coût annuel. |
